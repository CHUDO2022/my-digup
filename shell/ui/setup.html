DigUp

Опишите — и найдётся.

  • Фото и скриншоты «ошибка оплаты», «зебра», «доска с совещания во вторник»
  • Анализ архива похожие фото и видео собираются в группы, а модель сама даёт им названия
  • Моменты внутри видео «где задувают свечи», «кадр с салютом»

Всё происходит на этом компьютере. Программа один раз скачивает модель (865 МБ), дальше работает без интернета, и ваши файлы никуда не уходят. Сейчас она посмотрит ваши обычные папки и скажет, сколько времени займёт каждая; ничего не начнётся, пока вы не выберете.

Где искать фото и видео?

Отметьте папки; раскройте папку, чтобы исключить часть вложенных. Первый раз программа просмотрит всё целиком, а потом будет досматривать только новое.

Программа только читает файлы: ничего не меняет, не перемещает и не отправляет.

Search your code too?

DigUp can find code by what it does: type “code:” in the search panel and say what you're looking for. Code gets an index of its own and shows up only when you search for code. Pick the folders that hold your code, or leave them all and turn it on later in Settings.

DigUp reads what git keeps (not dependencies or build output). The time is reading it once; after that, only what changes is read again.

Поиск из любого места

Нажмите это сочетание клавиш в любой программе и опишите словами, что ищете.

В строке поиска

↩
открыть файл (видео — на найденном моменте)
Ctrl+↩
показать в папке
↑ ↓
переход между результатами
Пробел
показать крупно
Esc
закрыть

Всё готово

Программа живёт в трее (у часов) — там видно, как идёт просмотр, и там же «Анализ фото…». Закрытие этого окна её не останавливает.
